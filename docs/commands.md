# Commands

Five spoken commands: Follow, Stay, Fetch, Come, and Give. A match prints and speaks the command name. The rover does not follow, hold position, grasp, drive, or drop.

Accuracy comes from a short list. Each phrase belongs to one command. A word that could be two commands is not a command, so it cannot fire the wrong one. Say it again with a phrase from this page.

A listed phrase is decided by the grammar. Other wording can still match by meaning, and that path is stricter: it has to be clearly closer to one command than to ordinary speech and to the other commands. If it is close, the rover asks you to repeat it instead of guessing.

## Not commands

These used to collide with a real command. They are ignored. Say the phrase in the right column.

| Heard | Say instead |
|---|---|
| down | stay, or sit |
| set, place | stay. "Set it down" and "place the hammer" are Give |
| out, leave it | drop it |
| let's go | follow, or heel |
| get it, bring it | fetch the hammer |
| follow the instructions | follow me |

## Two commands in one breath

If both are clear and too close to separate, neither runs. The rover asks for one of them. A later command, after a pause, replaces the earlier one.
